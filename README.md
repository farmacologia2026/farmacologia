# Nombre de la plataforma

Aplicación web estática para practicar farmacología con preguntas tipo ENAM y Residentado Médico.

## Uso local

Abre `index.html` en un navegador moderno. No requiere instalación ni conexión a Internet.

## Publicar con GitHub Pages

1. Crea una cuenta en [GitHub](https://github.com/) si aún no tienes una.
2. Pulsa **New repository** y usa un nombre como `plataforma-farmacologia`.
3. Elige **Public** y crea el repositorio.
4. En la página del repositorio, selecciona **Add file → Upload files**.
5. Sube estos cuatro archivos desde esta carpeta:
   - `index.html`
   - `style.css`
   - `app.js`
   - `preguntas.js`
   - `WhatsApp Image 2026-08-01 at 2.10.26 PM.jpeg`
6. Pulsa **Commit changes**.
7. Abre **Settings → Pages**.
8. En **Build and deployment**, selecciona **Deploy from a branch**.
9. Selecciona la rama `main`, la carpeta `/(root)` y pulsa **Save**.
10. GitHub mostrará la dirección pública del sitio. Normalmente será:
    `https://TU-USUARIO.github.io/plataforma-farmacologia/`

La primera publicación puede tardar unos minutos. En adelante, para actualizar la aplicación solo reemplaza los archivos y confirma los cambios.

## Privacidad y uso responsable

- Las estadísticas se guardan únicamente en el navegador de cada usuario mediante `localStorage`.
- No incluyas datos identificables de pacientes ni credenciales en el repositorio.
- Al ser un sitio público, el código y el banco de preguntas podrán ser vistos y descargados por quien visite el enlace.
- Esta aplicación es de uso educativo y no sustituye guías clínicas actualizadas ni juicio profesional.
